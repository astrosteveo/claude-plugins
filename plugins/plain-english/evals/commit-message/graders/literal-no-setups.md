Grade only the writing style of the final answer, not its accuracy. Ignore code, commands, identifiers and quoted text.

Pass if the writing is literal and every sentence says something. Fail on any metaphor, idiom or slogan (for example "when it counts", "a beat late", "competent, not optimal"). Fail on any sentence whose only job is to set up or announce what comes next, whether cute or plain (for example "This is intentional.", "Here's the thing.", "Four rules keep that honest.", "The design follows four rules.", "Two problems caused this.", "Here's the breakdown:"). A sentence ending in a colon that introduces a list is fine when it carries information of its own (for example "Switch if any of these apply:").

In your reasoning, quote any text that breaks the rule.
